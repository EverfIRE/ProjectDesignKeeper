# Box2D Physics source audit

Read on 2026-08-30. Authority is limited to official Box2D and Erin Catto sources. Stable work is pinned to Box2D v3.1.1, released 2025-06-04 at commit 8c661469c9507d3ad6fbd2fea3f1aa71669c2fe3. Official fact: the release contains minor API changes but no documentation update, so website Doxygen 3.1.0 drifts behind the tagged public headers; those headers are final symbol authority for stable 3.1.1.

Current-main comparison is claim-scoped only. Commit 617d32ab02570930625bbcb8479f54be9bf8d045 identifies 3.2.0 experimental work including snapshot, recording, state hash, runtime worker, and additional CCD seams. Adapter policy: none of those symbols enter stable 3.1.1 code. Stable v3.1.1 has no public snapshot and no rollback support. Inference: replay from a complete ordered history may qualify an exact project build, but upstream determinism does not prove application rollback.
