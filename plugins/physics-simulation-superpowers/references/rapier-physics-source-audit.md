# Rapier Physics source audit

Read on 2026-08-30. Authority is limited to official Dimforge repositories, rapier.rs guides and generated APIs, docs.rs, crates.io, and npm. Rust is pinned to 0.35.3 at v0.35.3 and b82079ac41310a8af438af95b49b8fa551ce650f. JavaScript is pinned independently to 0.20.0 at js-v0.20.0 and 3e12c2679cb1940a876bde93af9cec0cf2f57944.

Documentation drift is material: the JavaScript determinism guide says all JS/WASM is cross-platform deterministic and uses obsolete createSnapshot(), while the pinned package matrix distinguishes deterministic flavors and the current generated API uses takeSnapshot(). The pinned package/source and current generated API win for their stated scopes. There is no Rust/JS snapshot guarantee and no cross-version snapshot guarantee. Upstream validation is an upstream seed, not application proof.

Governance boundary: an unknown-license community report was rejected and contributes no runtime claim, number, or instruction. Official pinned sources do not promise bounded memory across repeated restore cycles, so adapter policy requires an exact-artifact restore-frequency/WASM-memory soak against the declared budget. Deterministic input policy also requires exact bits, strict IEEE-754-2008, Rust ComplexField/RealField rather than native transcendental functions, no JavaScript Math.sin/Math.cos for independent deterministic initialization, and a negative cross-platform input-generation control.
