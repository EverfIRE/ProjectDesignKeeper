# NVIDIA PhysX native SDK source audit

Frozen native snapshot: NVIDIA-Omniverse tag `110.1-omni-and-physx-5.9.0`, released 2026-07-14, commit `517a0073715120e114ee055b63b26c95e00d9039`, `physx/version.txt` `5.9.0.6d94eeb9`. Sources were read on 2026-08-28. Every technical claim below is scoped to the stated official NVIDIA/NVIDIA-Omniverse authority and retains its limitation.

Conflict rule: when historical prose says TGS is the scene default but the pinned 5.9 `PxSceneDesc.h` initializes PGS, ePABP, and eENABLE_PCM, the pinned header wins for this snapshot. There is no standalone `MigrationTo59`; the pinned changelog and current headers/source bound the 5.9 migration. `ovphysx 0.5.10` is a separate pre-1.0 wrapper, not a stable native C++ 5.10 release. The public tree exposes snippets, but inspection found no auditable public SDK unit-test or benchmark target; changelog references to internal test names do not establish a public target.
